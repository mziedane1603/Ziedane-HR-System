Ziedane Hr System — حزمة مستقلة للرفع والتثبيت
==========================================

الحزمة دي فيها التطبيق ده لوحده، والمفروض يتحط في **أول (جذر) الـ repo أو الموقع** (index.html لازم يبقى في المستوى الأول).

🔐 أمان (مهم): النسخة دي بتسجّل الدخول عن طريق Firebase Authentication.
   اتبع ملف "Ziedane Security Setup.txt" (إنشاء الحسابات ونشر القواعد الجديدة).
   لحد ما تنشر القواعد الجديدة بيشتغل "وضع انتقالي" بتحذير ظاهر.

الرفع على GitHub Pages
-----------------------
1. اعمل repo جديد (خاص لو تقدر) واسمه أي حاجة.
2. فك الـ zip وارفع **كل الملفات واللي جواها فولدر icons** (index.html و manifest.json و sw.js وفولدر icons) في أول الـ repo.
   مهم: لو رفعت من المتصفح، اسحب فولدر icons نفسه مش الملفات اللي جواه بس.
3. Settings ← Pages ← Deploy from branch ← main ← / (root).
4. بعد دقيقة أو اتنين هيظهر الرابط:  https://USERNAME.github.io/REPO/
5. تأكد إن الأيقونة اترفعت: افتح  <رابطك>/icons/icon-192.png  لازم يظهر اللوجو.

التثبيت على أندرويد
--------------------
افتح الرابط في Chrome ← قائمة (⋮) ← "تثبيت التطبيق / Install app"
(أو زرار "📲 تثبيت التطبيق" اللي بيظهر فوق في التطبيق نفسه لو ظهر)

ملاحظات
--------
- لازم يتفتح من رابط HTTPS، مش من ملف محفوظ على الموبايل.
- لو هترفعه على Firebase Hosting، اعمل Site منفصل لكل تطبيق.
- لو قيّدت الـ API key بنطاقات معينة، ضيف نطاق الاستضافة الجديد.
